# Video provenance and verification

The revised product film is 4 minutes 35 seconds, 1920×1080, H.264/AAC, with English burned-in captions, WebVTT and a transcript. It presents the marketplace and discovery first, supplier and administrator dashboards next, the approval-to-inquiry workflow and WordPress bridge, then all five assistance areas.

Speech uses the local Kokoro ONNX model and stock `af_heart` neural voice. No voice cloning or remote speech service is used. The music is an original quiet sine-synth composition generated by the renderer; it contains no third-party music recordings or samples.

Model: [Kokoro-82M](https://huggingface.co/hexgrad/Kokoro-82M), Apache-2.0. Inference: [kokoro-onnx](https://github.com/thewh1teagle/kokoro-onnx), MIT. Model files downloaded from the author's model-files-v1.1 release remain in ignored `.runtime/tts/`; no model weights are published in the showcase.

This is an **edited evidence walkthrough**, not a continuous live screen recording. Verified historical interface captures are labeled separately from API-response explanatory graphics. The latter use `showcase/API_EVIDENCE.json`; the WordPress capture comes from a real local installation. Narrative feature descriptions also cover controls implemented after those recorded interface states. The public website hosts the review presentation, not the complete marketplace service.

All suppliers, vehicle records and rates are synthetic. The no-key assistance is deterministic. The optional external-model adapter has no verified live provider call. Image heuristics do not identify vehicles or verify ownership. Inquiry persistence was checked with fictional details, without sending real supplier messages.

## Reproduction

Use the API environment to install optional media tooling: `pip install kokoro-onnx==0.6.1 soundfile pillow imageio-ffmpeg`. Obtain the author's `kokoro-v1.0.onnx` and `voices-v1.0.bin` release assets in `.runtime/tts/`.

Run `scripts/demo/narrate-neural.py`, then `scripts/demo/render.py`, then `scripts/demo/package.py`. Windows fonts are used by the renderer. `verify-evidence.py` and `capture-proof.mjs` additionally require the local application/database and WordPress; they must not be run against production data. The legacy SAPI script remains available but was not used for this revision.

The source distribution excludes confidential assessment attachments, credentials, runtime state and Git history. Captions are approximately timed from narration length; they are not a word-aligned transcription.
